## Gotchas

- **Session admission:** quota counts issued starts, including abandoned/early-ended rounds. Firestore adds `users/{uid}.sessionDay/sessionCount` and `users/{uid}/liveStarts/{startId}` (setup fingerprint, pending lease and cached ephemeral token). Pending mints lease for 30 seconds; provider fetch times out after 20 seconds and failures refund only their own reservation. Token expiry stays fixed at admission (chosen length + 30 minutes); a very long pause requires a new round. Resumption reuses the same `uses: 1` token, per Google's [ephemeral-token guide](https://ai.google.dev/gemini-api/docs/live-api/ephemeral-tokens). These records are server-only and deleted by existing account deletion; they hold no audio/raw files. The cap applies to Live starts, not manuscript/rubric reading or report rescoring.
- **Testing session admission:** `DEEMO_LIVE_INTEGRATION=1 bun test tests/live.integration.test.ts` in `server/` uses real Firebase Auth/Firestore with one disposable `*@deemo.test` account, intercepts Gemini token minting, and cleans up its own records/account. It spends no AI credit. On this Windows sandbox, Bun tests/Doctor need execution outside the sandbox (otherwise module/alias resolution fails with `EBADFD`).
- **OpenAI backup:** the key is in `server/.env`. The account had no paid credit on 2026-10-10: `gpt-6-luna` answered, `gpt-6.1-sol` returned 429 `credit_balance_exhausted` (treated as busy). Add credit if Luna starts failing the same way; check the names on OpenAI's models page and set `OPENAI_MODELS` if they change. Accounts that consented before 2026-10.2 (including the user's) never use it.
- **Gemini overload:** under high demand the newest Flash models hang or answer 503 while older ones still work. The cooldown handles it; the first request after an outage starts can still take up to a minute. `thinkingLevel: "minimal"` is rejected by these models; use "low".
- **Gemini free tier:** the key is on the free tier: 20 Flash requests/day per model, and inputs may be human-reviewed. The fallback chain stretches the cap but doesn't fix privacy. **Paid tier is the open blocker** (user action).
- **GPG signing:** commits are signed and the passphrase prompt opens on the user's desktop. When it times out, leave the changes staged on the feature branch and give the user the commit command. Never use `--no-gpg-sign`.
- **Changing `.env.local`** needs a Metro restart with a clear cache (`bun start -c`); `EXPO_PUBLIC_*` values are baked in when the bundle is built.
- **adb over Wi-Fi:** when the phone reconnects (new port), `adb reverse` is lost and the app silently can't reach the server ("Getting the panel ready…"). Rerun `adb reverse tcp:3000 tcp:3000`.
- **Line endings:** many files are CRLF on disk. Scripted string replacements must normalize `\r\n` first, or use the Edit tool.
- **Testing on the device:** use throwaway Firebase accounts (`*@deemo.test`) and delete them afterwards (`recursiveDelete` on `users/{uid}`, then `deleteUser`). Don't change the user's own account settings; one stray tap once switched off "Allow typed answers".
- **Group integration test** (`server/tests/groups.integration.test.ts`) talks to the real Firebase project; it only runs with `DEEMO_GROUP_INTEGRATION=1` and cleans up its own `*@deemo.test` accounts.
- **Previewing the PDF without the phone:** render `reportHtml()` to an HTML file and print it with headless Chrome (`chrome --headless=new --no-pdf-header-footer --print-to-pdf=out.pdf file:///…`). Android's WebView prints the same way.
- **Waits:** new work the server is doing (reading a manuscript, scoring) uses `Working` (steps and a progress bar); opening something that already exists uses `Fetching`; a list loading for the first time uses `Skeleton` with bones shaped like its rows.
- **Rubrics:** a project has either `weights` (the default five criteria) or `rubric` (the panel's own, which wins). Report criteria come from whichever the session snapshotted, so old reports keep their criteria.
- **Deemo:** never on the live session, paused overlay or question card (design D4); its lines are scripted, at most two sentences, no exclamation marks (D3). Worklets (`useAnimatedStyle`) can't call plain JS helpers like Deemo's `u()`; compute numbers outside them first.
- **Rules:** never commit on `main`; never run native rebuilds (tell the user); risky work goes on its own branch and is merged into `dev` after testing (CLAUDE.md).
